# Glossário da matéria do versionamento

## O que é Git? 
Git é um lugar que você pode realizar as versões do arquivo no própio computador e pode utilizar sem internet.

## O que é Github?
O que Github é um site que você pode usar os repositórios para armazenar os arquivos realizados e permite o trabalho em equipe.

## Qual é a diferença?
O Git só pode realizar no própio computador, já Github pode trabalhar em grupo nos computadores diferentes.
O Git pode utilizar em momento sem internet,já Github não.

## O que é repositório?
É um lugar que armazenar os arquivos e versões realizados.

## O que é Commit?
É um ponto que salva todas as alterações realizados durante no trabalho.

## O que é branch?
É como um papel de rescunho que você pode colocar todas as ideias que você quer para arquivo.

## O que é Main?
É o branch principal que está as versões principais.

## O que é pull request?
É um pedido ou solicitação para colocar o seu branch no Main

## O que é Merge?
É quando realizar uma junçaõ entre um branch e main.
